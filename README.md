# 🧰 طراح پیچ و مهره سهند — Sahand Screw & Nut Designer

نرم‌افزار دسکتاپ **ویندوز** برای طراحی پارامتریک **پیچ، مهره، واشر و میلِ رزوه‌دار** با رزوهٔ واقعیِ مارپیچ، خروجی‌های مهندسی و آماده‌سازی چاپ سه‌بعدی — **کاملاً فارسی، راست‌چین و آفلاین**.

> نسخهٔ ۰٫۱٫۰ · .NET 8 (LTS) · WPF · بدون هیچ وابستگی NuGet در زمان اجرا

---

## ✨ قابلیت‌های کلیدی

- **رزوهٔ واقعی مارپیچ** (نه نمایشی): متریک ISO درشت/ریز، UNC، پروفیل سفارشی، چندشروع، چپ‌گرد، مخروطی — با تفکیک صریح `pitch` و `lead`
- **قطعات**: پیچ (شش‌گوش، آلن استوانه‌ای، خزینه، نیم‌گرد) · مهره شش‌گوش/جام · واشر تخت · میل رزوه‌دار · مجموعهٔ جفت با سازگارسنجی
- **محرک‌ها**: آلن، شیار تخت، فیلیپس — همهٔ مش‌ها **watertight** با آزمون خودکار
- **خروجی‌ها**: STL (باینری/ASCII)، OBJ، PLY، 3MF، GLB، DXF دوبعدی — با آزمون رفت‌وبرگشت (round-trip) از طریق خوانندهٔ مستقل
- **نسخهٔ چاپی جدا از نسخهٔ اسمی**: جبران‌های قابل تنظیم برای FDM/SLA/SLS + جدول مقایسه + کوپن آزمون رزوه
- **آفلاین واقعی**: طراحی/ذخیره/خروجی بدون اینترنت؛ ایمیل فقط با رضایت و تنظیم کاربر (صف محلی + SMTP امن با STARTTLS)
- **حریم خصوصی**: بدون تله‌متری، redaction راز/کارت/مسیر، DPAPI برای رمزها، شمارهٔ کارت پوشیده در صفحهٔ حمایت
- **CLI بدون رابط** (`ssnd-cli`) برای اتوماسیون و CI — روی Linux/Windows اجرا می‌شود
- **ارقام فارسی/لاتین**، ورود کسر اینچ، تبدیل دقیق mm↔inch بدون گردکردن بی‌صدا

## 🚀 ساخت و اجرا

```bash
dotnet build SahandScrewMaker.sln      # بیلد کل (روی Linux/Windows)
dotnet test SahandScrewMaker.sln       # اجرای ۱۱۳ آزمون
dotnet run --project src/Sahand.Cli -- make bolt --diameter 6 --length 20 --head hex --out bolt.stl
```

## 🗂️ ساختار مخزن

```
src/
  Sahand.Core/       # دامنه: رزوه، قطعات، واحد، اعتبارسنجی، کاتالوگ، .ssnd
  Sahand.Geometry/   # موتور مش: جاروب مارپیچ، سازنده‌های قطعه، اعتبارسنجی watertight
  Sahand.Exporters/  # STL/OBJ/PLY/3MF/GLB/DXF + خوانندهٔ round-trip
  Sahand.Reporting/  # صف گزارش، redaction، SMTP خام امن
  Sahand.Cli/        # CLI بدون رابط برای اتوماسیون
  Sahand.App/        # رابط WPF فارسی RTL + فونت وزیرمتن (OFL)
tests/               # ۵ پروژهٔ آزمون xUnit (۱۱۳ آزمون)
samples/             # ۴ پروژهٔ نمونهٔ .ssnd تولیدشده با CLI
prompts/             # اسناد مشخصات اولیهٔ پروژه (منبع الزامات)
analysis/            # تحلیل عامل پیش از پیاده‌سازی
```

## ⚠️ محدودیت‌های صادقانه

- **اجرای بصری WPF** روی ویندوز واقعی باید توسط کارفرما تأیید شود (توسعه روی Linux، بیلد سبز).
- **STEP AP242** در برنامهٔ توسعه است (نیازمند هستهٔ B-Rep) — صدور STEP جعلی از مش رد می‌شود.
- کاتالوگ دادهٔ آماده فقط ISO متریک و UNC؛ خانواده‌های دیگر (Whitworth/NPT/ACME…) پروفیل بدون کاتالوگ دارند.
