## ✨ معرفی

**«طراح پیچ و مهره سهند»** یک نرم‌افزار دسکتاپ مهندسی برای طراحی **پارامتریک** پیچ، مهره، واشر و میلهٔ رزوه‌دار با **رزوهٔ واقعی مارپیچ** (نه نمایشی) است؛ خروجی‌های آمادهٔ اسلایسر، نسخهٔ چاپی با جبران قابل تنظیم و ابزار خط فرمان برای اتوماسیون — همه **بدون اینترنت، بدون تله‌متری و بدون وابستگی زمانِ اجرا**.

### 🆕 تازه‌های نسخهٔ ۰٫۴٫۰

| | تغییر |
|---|---|
| 📤 | **کیفیت‌های خیلی عالی خروجی**: دو سطح جدید **فوق‌دقیق (۵۱۲ بخش زاویه‌ای)** و **حدی (۷۶۸ بخش + ریزترین گام مارپیچ)** — قطعهٔ نرم‌تر با مش‌های خیلی زیاد؛ نمونهٔ واقعی: پیچ M8×30 با **۵٫۷ میلیون وجه** در ~۱٫۵ ثانیه. ضمناً کیفیت انتخابی حالا **واقعاً اعمال می‌شود** (قطعه با تفکیک انتخابی بازسازی می‌شود — پیش از این فقط برچسب گزارش بود!) |
| 🔩 | **سرهای جدید: دکمه‌ای (Button) و فلنجی (Flange)** — گنبد سهمی کم‌انحنا با پلتفرم قله (مدل DIN 913) و دیسک فلنج با شانهٔ گذار برای توزیع فشار |
| 🔐 | **محرک‌های امنیتی پین‌دار**: **آلن امنیتی (PinHex)** و **تورکس امنیتی (SecurityTorx)** — پین مرکزی واقعی که آچار معمولی را قفل می‌کند؛ روی هر چهار سر حفره‌پذیر |
| 🎨 | **خوانایی بازطراحی‌شده**: منوی کناری آبی فولادی روشن‌تر با متن سفید خالص (رفع کامل «تیره روی تیره») + **آیکون برند بزرگ‌تر (۷۶px)** + فونت منو ۱۶px |
| 🧊 | **کیفیت ساخت مدل در فرم طراحی** (پیش‌فرض «دقیق») — پیش‌نمایش هم نرم‌تر شد |

## 🚀 شروع سریع

### 🖱️ برنامهٔ روان (ویندوز)

1. بستهٔ نصب یا پرتابل را از [رلیزها](https://github.com/pranses2011/Sahand_Screw_Maker/releases) بگیرید — نیازی به نصب .NET نیست.
2. از «خانه» یک **پیچ جدید از کاتالوگ** بسازید یا نمونهٔ آماده را باز کنید.
3. **خانوادهٔ رزوه** (متریک/اینچی/ویتوورث/NPT/BSPP/ذوزنقه‌ای/ACME) و اندازه را انتخاب کنید؛ یادداشت منبع همان‌جا نمایش داده می‌شود.
4. ابعاد/رزوه را تنظیم و مدل را بسازید؛ **اعتبارسنجی هندسی** همان لحظه نتیجه را می‌گوید.
5. در صورت نیاز **نسخهٔ چاپی** با جبران‌ها مشتق کنید و **جدول تفاوت** را ببینید.
6. از بخش «خروجی» با فرمت و کیفیت دلخواه، فایل بگیرید.

### ⌨️ ابزار خط فرمان (ویندوز و لینوکس)

```bash
# ساخت پیچ شش‌گوش M6×20 با خروجی STL
ssnd-cli generate --part bolt --size M6 --length 20 --head Hex --export STL --out bolt.ssnd

# سرهای جدید ۰٫۴٫۰: دکمه‌ای آلن‌دار و فلنجی تورکس امنیتی با پین
ssnd-cli generate --part bolt --size M8 --head Button --drive HexSocket --length 22 --export STL --out button.ssnd
ssnd-cli generate --part bolt --size M8 --head Flange --drive SecurityTorx --pin-diameter 1.8 --length 22 --export STL --out flange.ssnd

# محرک امنیتی آلن با پین + کنترل قطر پین
ssnd-cli generate --part bolt --size M10 --head SocketCap --drive PinHex --pin-diameter 2.2 --export OBJ --out pinhex.ssnd

# کیفیت‌های خیلی عالی ۰٫۴٫۰ — مش‌های خیلی زیاد و قطعهٔ نرم‌تر
ssnd-cli generate --part bolt --size M8 --length 30 --quality ultra --export STL --out smooth-ultra.ssnd
ssnd-cli generate --part bolt --size M8 --length 30 --quality extreme --export STL --out smooth-extreme.ssnd   # ۵٫۷ میلیون وجه!

# پیچ آلن با حفرهٔ تورکس (۰٫۳٫۰)
ssnd-cli generate --part bolt --size M8 --head SocketCap --drive Torx --length 22 --export STL --out torx.ssnd

# پیچ ویتوورث و میل NPT مخروطی و ذوزنقه‌ای (خانواده‌های ۰٫۳٫۰)
ssnd-cli generate --part bolt --size "1/4-20 BSW" --head Hex --length 16 --export OBJ --out bsw.ssnd
ssnd-cli generate --part rod --size "1/2-14 NPT" --length 26 --export STL --out npt.ssnd
ssnd-cli generate --part rod --size "Tr20×4" --length 28 --export OBJ --out tr.ssnd

# مهرهٔ M8 با رزوهٔ داخلی واقعی + خروجی 3MF
ssnd-cli generate --part nut --size M8 --export 3MF --out nut.ssnd

# مجموعهٔ جفت با واشر
ssnd-cli generate --part assembly --size M6 --length 20 --washer --export OBJ --out asm.ssnd

# کوپن آزمون رزوه (۴ گام) برای تنظیم فیت پیش از چاپ کامل
ssnd-cli coupon --size M6 --export STL --out coupon.ssnd
```

### 📇 کاتالوگ رزوه‌ها — هفت خانوادهٔ کاتالوگی

| خانواده | پروفیل | سری‌ها | نمونه |
|---|---|---|---|
| ISO متریک | ۶۰° | درشت + ریز | M1 … M48 |
| یونیفاید اینچی | ۶۰° | UNC + **UNF** | #0-80 … 1-1/2-12 |
| ویتوورث | ۵۵° | BSW + **BSF** | 1/8-40 … 3-3.5 |
| NPT لوله‌ای | ۶۰° + مخروط ۱:۱۶ | NPT | 1/16-27 … 6-8 |
| BSP لوله‌ای | ۵۵° موازی | BSPP (G) | G1/16-28 … G2-11 |
| ذوزنقه‌ای ISO | نیم‌زاویهٔ ۳۰° | Tr | Tr8×1.5 … Tr48×8 |
| ACME | نیم‌زاویهٔ ۱۴٫۵° | عمومی | 1/4-16 … 3-2 |

> داده‌ها «بر پایهٔ» سری‌های شناخته‌شدهٔ مهندسی‌اند (ISO 261، ASME B1.1، ISO 262/BS 84، ASME B1.20.1، ISO 228، ISO 2901، ASME B1.5)؛ یادداشت منبع هر مدخل در UI و فایل پروژه حمل می‌شود و ادعای انطباق رسمی مطرح نمی‌شود.

## ⚠️ محدودیت‌های صادقانهٔ نسخهٔ ۰٫۴٫۰

- **اجرای بصری WPF** (به‌ویژه ظاهر رندر پیش‌نمایش و تم بازطراحی‌شده) روی ویندوز واقعی باید تأیید شود (توسعه روی Linux، بیلد سبز؛ تصاویر رابط، بازتولید وفادار قالب‌های XAML‌اند). در صورت مشاهدهٔ خطای جدید، فایل `crash-log.txt` (پوشهٔ دادهٔ برنامه) اثر ماندگار دارد.
- **نصب‌کنندهٔ NSIS** روی Linux کامپایل شده؛ فرایند نصب روی ویندوز باید آزموده شود.
- دادهٔ کاتالوگ «بر پایهٔ» سری‌های شناخته‌شدهٔ مهندسی است (ادعای انطباق رسمی مطرح نمی‌شود)؛ خانواده‌های **مربعی و سفارشی** پروفیل بدون کاتالوگ دارند.
- **NPT** هندسهٔ مخروطی واقعی دارد اما «آب‌بندی» لوله‌ای (مهرهٔ مخروطی/درزچسب) از دامنهٔ نرم‌افزار خارج است.
- شیار روی سر شش‌گوش/خزینه/دکمه‌ای (گنبد) و محرک‌های امنیتی **تک‌جهته (OneWay) و دو-حفره‌ای (Spanner)** در برنامهٔ توسعه‌اند و در اعتبارسنجی صادقانه رد می‌شوند — هندسهٔ رمپ مورب/حفره‌های زوج واقعی نیاز دارد و تولید تقریبی جایگزین نمی‌شود.
- برای مش‌های بزرگ‌تر از ۲۵۰٬۰۰۰ وجه (کیفیت فوق‌دقیق/حدی) بررسی **تقاطع خودی** با پیام صادقانه «انجام نشد» رد می‌شود (هزینهٔ محاسباتی)؛ watertight/جهت‌دهی کامل بررسی می‌شوند.
- **STEP AP242** عمداً در برنامهٔ توسعه است: صدور STEP از مش مثلثی ممنوعِ سند ۴ است (فایل جعلی) و هستهٔ B-Rep واقعی نیاز دارد.
- تقاطع خودی مش «هیوریستیکی» است (کشف قطعی تضمین‌نشده) — در کد مستند شده.
