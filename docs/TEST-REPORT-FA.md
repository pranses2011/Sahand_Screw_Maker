## ۳. آزمون‌های اجرا‌نشده — صداقت محیط (سند ۶-۱۰)

این محیط توسعه **Linux** است؛ بنابراین:

1. **اجرای پنجرهٔ WPF، رندر وزیرمتن، DPAPI و رفتار HIDPI** روی این ماشین آزمون نشده — کد جدا و build سبز است اما «تأییدنشده روی Windows» باقی می‌ماند تا روی ویندوز واقعی اجرا شود. ادعایی مطرح نمی‌شود.
2. **بازکردن خروجی‌ها در نرم‌افزار CAD/اسلایسر تجاری** (فری‌کدکس و…) انجام نشده؛ round-trip با خواننده‌های مستقل داخلی آزموده شده است.
3. **نصب‌کنندهٔ آفلاین ویندوز** ساخته نشده؛ دستور `dotnet publish -r win-x64 --self-contained` در BUILD-FA.md مستند است و بستهٔ خودکفا بدون دانلود زمان اجرا می‌سازد.
